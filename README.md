# Seend - Mensajería Instantánea

App de mensajería instantánea desarrollada con Kotlin y Jetpack Compose.

## Características
- Registro e inicio de sesión
- Chat en tiempo real con WebSocket
- Indicador de escritura
- Confirmación de lectura
- Perfil de usuario con foto

## Tecnologías
- Kotlin
- Jetpack Compose
- Retrofit
- OkHttp WebSocket
- DataStore
